# Shared

`shared/` contém building blocks de apresentação e utilidades realmente reutilizáveis entre múltiplas features.

Exemplos adequados:

- componentes de UI reutilizáveis;
- directives;
- pipes;
- utilitários stateless.

Não coloque aqui lógica de negócio específica de feature nem uma camada genérica catch-all de services.
