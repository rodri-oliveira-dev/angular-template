# Shared

`shared/` contains presentation and utility building blocks that are genuinely reusable across multiple features.

Suitable examples:

- reusable UI components;
- directives;
- pipes;
- stateless utilities.

Do not place feature-specific business logic or a generic catch-all service layer here.
