# Architecture Decision Records

ADRs registram decisões que moldam o template reutilizável e devem permanecer estáveis entre aplicações geradas.

| ADR                                        | Status | Decisão                            |
| ------------------------------------------ | ------ | ---------------------------------- |
| [0001](0001-feature-first-architecture.md) | Aceito | Arquitetura Angular feature-first |

## Adicionando um ADR

Crie um novo arquivo Markdown numerado quando uma mudança introduzir uma restrição arquitetural duradoura ou reverter uma decisão aceita. Inclua contexto, decisão, consequências e alternativas consideradas.

Não use ADRs para detalhes rotineiros de implementação que possam ser explicados no guia técnico correspondente.
