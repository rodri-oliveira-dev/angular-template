# v1.2.0 — Segurança e manutenção da release

Release prevista para 2026-10-24. A publicação ocorre apenas após o merge deste PR e a execução manual do workflow **Release** a partir da `main`.

A versão `1.2.0` mantém alinhados o template de aplicação Angular 22 e a distribuição npm dos Schematics, sem modificar as opções públicas de geração.

## Destaques

- demonstração no GitHub Pages e workflow de publicação;
- atualizações agrupadas do Dependabot na aplicação raiz, GitHub Actions e `schematics/`;
- atualização de Angular 22 e das ferramentas de desenvolvimento;
- resoluções corrigidas `fast-uri@3.1.9` e `vite@8.3.5` garantidas por npm overrides;
- manutenção de CI, CodeQL, release e workflows de publicação.

## Validação

O PR anterior de atualização de dependências passou na instalação limpa, `npm audit --audit-level=high`, cobertura, build, Playwright E2E, OWASP ZAP e integração do consumidor Schematics. Este PR de release também deve passar em seus próprios checks.

## Publicação

Após o merge e CI aprovado, execute [Release](../../../.github/workflows/release.yml) a partir da `main`. O workflow cria `v1.2.0` e dispara `publish-schematics.yml`, sujeito à aprovação configurada para o ambiente npm.

Não recrie tags existentes nem publique a partir da branch do PR.
