# v1.1.0 — Distribuição via Angular Schematics

Lançamento: 2026-10-05

A v1.1.0 distribui o template de aplicação pronto para produção como a coleção npm Schematics
isolada `@rodri-oliveira-dev/angular-template`. A aplicação raiz continua privada e executável; nenhuma library
de runtime foi introduzida.

## Destaques

- experiência padrão `ng new my-app --collection=@rodri-oliveira-dev/angular-template`;
- composição do schematic oficial `ng-new` do Angular CLI;
- baseline determinístico de arquitetura feature-first, HTTP/API, segurança, testes,
  observabilidade, CI, workspace e BFF;
- estilos, routing, modo mock/BFF, target do proxy, observabilidade, E2E e cobertura configuráveis;
- normalização segura da identidade e proteção contra geração repetida;
- suíte unitária em árvore virtual e validação clean-room completa do consumidor gerado;
- tarball npm mínimo inspecionado e trusted publishing via OIDC controlado por tag Git.

## Baseline validado

- Angular/CLI 22.2.x;
- TypeScript 6.0.x;
- Node.js 24.15.0+ na linha Node 24;
- `npm ci` limpo, sem overrides de peer dependencies;
- formatação, lint, guardrails de arquitetura/segurança, testes de segurança e audit;
- 70 testes unitários com todas as métricas acima do gate de 85%;
- builds de produção e bootstrap limpo;
- fluxos de browser Playwright mock e BFF;
- instalação do pacote e carregamento da coleção fora do checkout de origem.

Consulte [Distribuição via Angular Schematics](../schematics.md) para instalação, todas as opções,
desenvolvimento local, validação do pacote e pré-requisitos de release.

O publish no registry continua controlado pela tag `v1.1.0` e pela configuração de trusted
publisher no npm; nenhum pacote npm foi publicado durante implementação ou smoke test.
