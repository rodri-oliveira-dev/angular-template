# v1.0.0 — Production-ready Angular Template

v1.0.0 is the first production-ready baseline of the template.

## Highlights

- Angular 22.2.x / TypeScript 6.0.x strict standalone baseline;
- feature-first architecture with automated cross-feature boundary enforcement;
- typed same-origin HTTP/API integration with correlation and Problem Details;
- zero-infrastructure local mock mode;
- optional BFF mode with documented session, XSRF, CORS, and responsibility boundaries;
- Vitest unit tests and Playwright mock/BFF browser contracts;
- 85% minimum coverage for statements, branches, functions, and lines;
- ESLint, Prettier, npm audit, CodeQL, Dependabot, OWASP ZAP, and frontend security checks;
- vendor-neutral observability with optional OpenTelemetry exporter boundary;
- clean-bootstrap verification from an isolated copy;
- CI PR status comment identifying failed/skipped gates;
- complete getting-started, architecture, HTTP, testing, quality, security, observability, CI, BFF, contribution, and security-policy documentation.

## Bootstrap

```bash
nvm use
npm ci
npm start
```

No external infrastructure is required for the default development mode.

## Validation

```bash
npm run ci:verify
```

The repository also exposes `npm run bootstrap:verify` to validate installation and production build from a clean temporary copy.

## Compatibility

The release is validated on Node.js 24.15.0+ in the Node 24 line with the Angular 22.2.x and TypeScript 6.0.x toolchain resolved by the committed lockfile.

TypeScript 7 is intentionally not forced into this release because the current Angular/build/lint compatibility ranges require TypeScript 6.0.x.

## Distribution

v1.0.0 is intended to be distributed first as a GitHub Template Repository. npm/Angular Schematics distribution is a planned post-v1.0 evolution.

## Upgrade notes

There is no prior stable release migration requirement. Existing pre-v1 consumers should compare their local customizations before adopting the v1.0 baseline.

## Release process

Create/tag `v1.0.0` only after the v1.0 PR is merged and CI + CodeQL are green on `main`.
