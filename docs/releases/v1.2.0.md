# v1.2.0 — Security and release maintenance

Target release: 2026-10-24. This package is published only after merging this PR and manually running the **Release** workflow from `main`.

Version `1.2.0` keeps the Angular 22 application template and npm Schematics distribution aligned, without changing the public generation options.

## Highlights

- GitHub Pages demo and deployment workflow;
- weekly grouped Dependabot updates for the root application, GitHub Actions, and `schematics/`;
- Angular 22 and developer toolchain updates;
- patched resolutions `fast-uri@3.1.9` and `vite@8.3.5` enforced through npm overrides;
- maintained CI, CodeQL, release, and publishing workflows.

## Validation

Prior dependency-remediation checks passed: clean installation, `npm audit --audit-level=high`, coverage, build, Playwright E2E, OWASP ZAP, and packaged Schematics consumer integration. This release PR must pass its own checks.

## Publish

After the release PR is merged and CI succeeds, run [Release](../../.github/workflows/release.yml) from `main`. This creates `v1.2.0` and dispatches `publish-schematics.yml`, subject to the configured npm environment approval.

Do not recreate existing release tags or publish from the PR branch.
