# v1.1.0 — Angular Schematics distribution

Released: 2026-10-05

v1.1.0 distributes the production-ready application template as the standalone npm Schematics
collection `@rodri/angular-template`. The root application remains private and executable; no
runtime library was introduced.

## Highlights

- standard `ng new my-app --collection=@rodri/angular-template` experience;
- composition of the official Angular CLI `ng-new` schematic;
- deterministic feature-first, HTTP/API, security, testing, observability, CI, workspace, and BFF
  baseline;
- configurable styles, routing, mock/BFF mode, proxy target, observability, E2E, and coverage;
- safe project identity normalization and guarded repeat generation;
- virtual-tree unit suite and full generated-consumer clean-room validation;
- inspected minimal npm tarball and Git-tag-gated OIDC trusted publishing.

## Validated baseline

- Angular/CLI 22.2.x;
- TypeScript 6.0.x;
- Node.js 24.15.0+ in Node 24;
- clean `npm ci` without peer-dependency overrides;
- formatting, lint, architecture/security guardrails, security tests/audit;
- 70 unit tests with every coverage metric above the 85% gate;
- production and clean-bootstrap builds;
- Playwright mock and BFF browser flows;
- package installation and collection loading outside the source checkout.

See [Angular Schematics distribution](../schematics.md) for installation, every option, local
development, package validation, and release prerequisites.

The registry publish itself remains controlled by the `v1.1.0` tag and npm trusted-publisher setup;
no npm package was published during implementation or smoke testing.
