# Architecture Decision Records

ADRs record decisions that shape the reusable template and should remain stable across generated applications.

| ADR                                        | Status   | Decision                           |
| ------------------------------------------ | -------- | ---------------------------------- |
| [0001](0001-feature-first-architecture.md) | Accepted | Feature-first Angular architecture |

## Adding an ADR

Create a new numbered Markdown file when a change introduces a durable architectural constraint or reverses an accepted decision. Include context, decision, consequences, and alternatives considered.

Do not use ADRs for routine implementation details that can be explained in the relevant technical guide.
